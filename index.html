PRIVACY AND DATA

Your plan stays in this browser

This site is publicly hosted on GitHub Pages, so its application files are public. Personal plan data you enter or import is stored in this browser’s local storage and is not included in those public files.

No account or cloud sync

There is no account, server database, or device synchronization. A different browser or device will not see this plan. Clearing browser site data may permanently erase it.

Backups

Use Export & print → Download JSON backup to save a local backup. Use Restore JSON to preview and import it on this or another device.

Deleting data

Settings contains controls to reset to a blank plan, load fictional demo data, or delete every tracker record stored by this site in the current browser.

Network requests

The app makes only normal requests for its static HTML, CSS, and JavaScript files when hosted. It has no analytics, telemetry, remote logging, cloud storage, or network file parser. Degree-plan data and imported file contents are not transmitted. External catalog links open only when you choose them.

PDF imports

PDF import is not supported because this dependency-free app does not include a verified local-only PDF parser. Use JSON backups or enter evaluated credits manually.

IMPORTANT

This is an educational planning tool, not an official degree audit. SNHU decides how transfer, credential, and third-party credit applies. Requirements and equivalencies can change.
